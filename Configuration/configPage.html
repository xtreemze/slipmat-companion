Installation

Audio analysis is built into the plugin and uses Jellyfin's managed FFmpeg. No analyzer URL, second container, or shared media mount is required. Missing artifacts are generated asynchronously and a daily Jellyfin scheduled task reconciles the library.
Leave blank to use a writable directory managed under Jellyfin's data path. Existing deployments with a mounted /store remain compatible. SLIPMAT_ARTIFACT_STORE_ROOT can provide an environment override.
