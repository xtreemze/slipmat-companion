Installation

Audio analysis is built into the plugin and uses Jellyfin's managed FFmpeg. No analyzer URL, second container, or shared media mount is required. Missing artifacts are generated asynchronously and the scheduled backfill reconciles the library.
Leave blank to use a writable directory managed under Jellyfin's data path. Existing deployments with a mounted /store remain compatible. SLIPMAT_ARTIFACT_STORE_ROOT can provide an environment override.

Jottacloud media projection

Install and authenticate Jottacloud CLI on this server yourself. The companion never receives login credentials; it manages the already-authenticated local jottad through jotta-cli. Media is materialized one-way into a dedicated local projection before Jellyfin scans it. The host may set SLIPMAT_JOTTACLOUD_CLI when jotta-cli is not available on Jellyfin's PATH.
Must be a dedicated absolute directory. Slipmat refuses a non-empty directory it has not previously claimed for this exact remote folder and never deletes its contents.
Save configuration, then check the authenticated daemon. 

                    


                    

                        
iptv-org Live TV discovery

                        

                            Browse the public iptv-org JSON catalog and subscribe channels to this Jellyfin server.
                            Selected channels are published through Jellyfin's native Live TV service, including
                            per-stream Referer/User-Agent requirements when provided by iptv-org. This server-wide
                            source configuration is separate from Slipmat's per-user client subscription library.
