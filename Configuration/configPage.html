Installation

Audio analysis is built into the plugin and uses Jellyfin's managed FFmpeg. No analyzer URL, second container, or shared media mount is required. Missing artifacts are generated asynchronously and the scheduled backfill reconciles the library.
Leave blank to use a writable directory managed under Jellyfin's data path. Existing deployments with a mounted /store remain compatible. SLIPMAT_ARTIFACT_STORE_ROOT can provide an environment override.

Cloud media — Jottacloud / Telia / Tele2

Browse the cloud account from this server, choose a remote media folder, and let Audio Gateway materialize it into a Jellyfin library. The first-party Jottacloud CLI must be installed and authenticated in the same OS/container context as Jellyfin. Audio Gateway never asks for or stores the cloud password, Personal Login Token, OAuth token, or cookies.

Cloud folder browser

Open the browser after the server reports that Jottacloud is ready.
The certified Jottacloud CLI exposes remote browsing and download, but no documented remote mkdir operation. To create a new cloud folder, create it in Jottacloud/Telia/Tele2 first, then return here and open it.
This is the remote folder Audio Gateway will mirror one-way for Jellyfin scanning.
Advanced local storage
Leave blank for a dedicated directory managed under Jellyfin's data path. Set an absolute path only when the cloud cache belongs on another mounted volume. Audio Gateway never deletes projected media and refuses non-empty directories it does not own.

iptv-org Live TV discovery

Browse the public iptv-org JSON catalog and subscribe channels to this Jellyfin server. Selected channels are published through Jellyfin's native Live TV service, including per-stream Referer/User-Agent requirements when provided by iptv-org. This server-wide source configuration is separate from Slipmat's per-user client subscription library.
