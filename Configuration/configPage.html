Installation

The Jellyfin plugin is usable immediately after installation and restart. It provisions its own persistent companion store inside Jellyfin. No analyzer service or /store mount is required for core companion features.
Optional health endpoint for a separately deployed Slipmat audio analyzer. Leaving this blank is normal and is not a degraded state. SLIPMAT_ANALYZER_URL takes precedence when set by the Jellyfin host environment.
Leave blank to use a writable directory managed under Jellyfin's data path. Existing deployments with a mounted /store remain compatible. If /store is an untouched 0.1.0.0 default and no mount exists, it is ignored in favor of managed storage. SLIPMAT_ARTIFACT_STORE_ROOT can provide an environment override.
