Project story

Useful work, closer to the media.

Slipmat Companion exists to move expensive, repetitive or browser-constrained work nearer to Jellyfin without moving product authority there. The project grows by adding optional capabilities that can disappear without making Slipmat stop being Slipmat.

North star

Accelerate more. Own less.

Companion is not another media server or playback engine. It is an optional capability layer for work that benefits from server proximity: analysis, batching, protected acquisition bridges, provenance-rich metadata, bounded cloud projection and diagnostics.

  • Keep playback authority in Slipmat. Companion can prepare evidence and sources, but it does not own the queue, transport clock, renderer or Playback Rail.
  • Keep media authority in Jellyfin and source providers. Server-side acceleration must not create a second canonical catalog or silently take ownership of remote media.
  • Make absence ordinary. If Companion is missing, unhealthy or lacks an optional module, Slipmat should degrade to canonical fallback paths rather than fail as a product.
  • Prefer measured, provenance-bearing evidence. Analysis and metadata should be reproducible and attributable instead of turning server inference into hidden policy.
