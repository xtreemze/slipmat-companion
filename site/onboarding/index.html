Guided setup

Connect Companion.

Complete the required Jellyfin installation first. Cloud projection and provider credentials are optional and should only be configured when you need those modules.

Required

Your progress is stored only in this browser. These controls do not configure Jellyfin or send data anywhere.

In Jellyfin, open Dashboard → Plugins → Repositories and add:

https://xtreemze.github.io/slipmat-companion/manifest.json

Open the Jellyfin plugin catalog, install Audio Gateway, then restart Jellyfin so the plugin can register its native services and dashboard page.

Open the Audio Gateway dashboard in Jellyfin. Core batching and integrated analysis should work without an external analyzer. Missing optional modules are ordinary fallback conditions.

For protocol-level verification, the plugin exposes /Plugins/AudioGateway/diagnostics/capabilities.

Optional modules

Enable only the capabilities you intend to use. These remain adapters and accelerators, not new canonical state owners.

PODCASTS

Podcast Index search

Configure Podcast Index API credentials as Jellyfin host environment variables. Secrets stay server-side and are never emitted to browser clients.

CLOUD

Read-only rclone VFS

Install and configure rclone on the Jellyfin host, then create bounded VFS profiles in the plugin dashboard. Companion does not expose rclone RC.

ADVANCED

Artifact store override

The plugin provisions its own writable store by default. Override it only for deployments that intentionally manage a dedicated location.

Cloud-mounted media is excluded from automatic Companion analysis traversal. Missing cloud analysis remains request-driven so a scheduled background pass cannot materialize an entire remote library.

Continue in Slipmat.

Once Jellyfin reports the extension as healthy, Slipmat can negotiate the optional modules it understands. No separate Companion login or second media library is required.
