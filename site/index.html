A companion, not a dependency.

The plugin accelerates work that Slipmat can still perform through canonical client and Rust paths. If the extension is absent, unhealthy, or partially configured, the client falls back instead of treating Companion as product authority.

01 / ANALYZE

Precompute audio evidence

Waveform, spectral, loudness, rhythm, source-boundary, harmonic-key and energy evidence can be prepared ahead of playback.

02 / BRIDGE

Reduce browser constraints

Authenticated podcast, guide, directory and bounded media-relay endpoints provide server-side acquisition where browser CORS prevents direct access.

03 / PROJECT

Keep cloud storage bounded

Optional rclone VFS profiles expose remote namespaces read-only while keeping source media authoritative and local cache disposable.

Evolution

Built by removing unnecessary authority.

Companion began on 1 October 2026 as a standalone Jellyfin extension for work useful to precompute near the media server. It expanded into higher-order audio evidence, provider-neutral server bridges, artwork palettes and bounded read-only cloud projection while keeping Slipmat playback and Jellyfin catalog authority intact.
